
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Implemente em Python um jogo da Forca para praticar manipulação de strings, loops, condicionais, seleção aleatória e entrada de dados do usuário. O jogador deverá revelar uma palavra oculta antes de esgotar as tentativas permitidas.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição

Complete o código inicial em `starter-code.py` para selecionar uma palavra e conduzir uma partida da Forca pelo terminal. A cada rodada, o jogador deve informar uma letra e acompanhar o progresso da palavra.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista predefinida no código inicial.
- Exibir cada letra ainda não adivinhada como `_` e revelar as letras acertadas nas posições correspondentes.
- Solicitar palpites de letras e registrar os palpites corretos e incorretos.
- Controlar o número de tentativas incorretas restantes e encerrá-las quando o limite for atingido.
- Encerrar a partida quando a palavra for revelada ou o limite de tentativas incorretas for atingido.
- Exibir uma mensagem de vitória ou derrota de acordo com o resultado.
